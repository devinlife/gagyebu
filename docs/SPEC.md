# gagyebu 명세

PoC의 끝 모습이다. 기능은 작업 단위로 나눠 하나씩 더한다. 여기 적힌 관례는 처음부터 지킨다.

## 데이터

- JSON 파일 하나. 경로는 `--data <경로>` > 환경 변수 `GAGYEBU_DATA` > `~/.gagyebu/data.json` 순으로 정한다.
- 쓰기는 같은 폴더의 임시 파일에 쓴 뒤 rename한다(쓰다 끊겨도 원본이 남는다).
- 최상위에 `version`(스키마 버전 정수)을 둔다. 옛 버전 파일은 읽을 때 올려 쓴다.
- 금액은 원 단위 양의 정수. 거래: `id`(늘어나는 정수, 다시 쓰지 않는다), `date`(`YYYY-MM-DD`), `type`(`income`·`expense`·`transfer`), `amount`, `category`, `account`, `memo`, `tags`(문자열 배열).

## CLI 관례

- `gagyebu <명령> [인자] [--옵션 값]`. `gagyebu help`와 `gagyebu <명령> --help`가 사용법을 보인다.
- 종료 코드: 성공 0, 데이터·처리 오류 1, 사용법 오류(모르는 명령·옵션, 빠진 인자, 잘못된 값) 2.
- 오류는 stderr에 `오류: <무엇이 왜>` 한 줄. 사용법 오류는 그 아래 해당 명령의 사용법 한 줄을 붙인다.
- 사용자에게 보이는 문구(오류, 확인 줄, 안내)는 합니다체로 쓴다(예: `…여야 합니다`, `…없습니다`).
- 목록·요약을 내는 명령은 `--json`으로 기계 판독 출력을 낸다.
- 금액 출력은 천 단위 쉼표와 `원`(예: `12,300원`). 표는 칸을 맞춘다(한글은 두 칸 폭으로 센다).

## 기능(끝 모습)

- 거래: 추가·목록·수정·삭제, 날짜·금액 입력 편의(오늘·어제, `1만2천` 등)
- 분류 관리, 계좌와 이체, 계좌별 잔액
- 월 요약(분류별 합계), 예산과 사용률, 연간 보고, 터미널 막대 차트
- 검색과 태그, CSV 내보내기·가져오기, 반복 거래
- 되돌리기, 백업·복원
- 로컬 웹 서버(`127.0.0.1`): JSON API, 보고서 페이지, 거래 추가 폼
